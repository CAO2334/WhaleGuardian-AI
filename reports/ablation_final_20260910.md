# 最终完整消融实验报告

本报告合并 AutoDL 运行 `autodl_research_20260909-023128`（01–07）与 `autodl_remaining_20260909-173306`（08–17）的 17 组结果。所有实验均使用随机种子 42、20 个 epoch、确定性训练设置，以及同一份按 `individual_id` 分组的固定数据划分。独立测试集不参与 checkpoint、消融配置或集成权重选择。

## 数据与完整性审计

- 类别数：28
- 训练/验证/独立测试：40,277 / 5,409 / 5,347 张
- train/validation/test 的 `individual_id` 两两重叠数：0
- 01–17 的类别映射、train/validation/test CSV 内容哈希完全一致
- 固定划分 SHA256：train `11419f29d9f7...`、validation `25a237422b35...`、test `e55ad4744528...`
- 17 个实验均包含 checkpoint、训练指标、类别映射、固定划分和 TensorBoard 日志

## 17 组验证结果

模型只按验证 Macro F1 排名。`Δ Macro F1` 以最终单模型 07 为基准，单位为百分点。

| 编号 | 模型或单变量改动 | Val Accuracy | Val Macro F1 | Δ Macro F1 |
|---|---|---:|---:|---:|
| 01 | ResNet50 + CE + Resize | 97.69% | 93.35% | -1.52 |
| 02 | 01 + Random Resized Crop | 97.93% | 94.02% | -0.85 |
| 03 | Metric + GAP + Linear head + Crop | 98.00% | 93.32% | -1.55 |
| 04 | 03：GAP → GeM | 98.24% | 93.75% | -1.12 |
| 05 | 04：Linear → Sub-center ArcFace | 98.17% | 93.78% | -1.09 |
| 06 | 多尺度 Transformer + CE + Crop | 98.06% | 94.25% | -0.62 |
| **07** | **多尺度 Transformer + Focal + Mixup + Cutout** | **98.23%** | **94.87%** | **0.00** |
| 08 | 07：Focal → CE | 97.25% | 92.82% | -2.05 |
| 09 | 07：关闭 Mixup | 97.54% | 93.31% | -1.56 |
| 10 | 07：关闭 Cutout | 97.60% | 93.66% | -1.21 |
| 11 | 07：Resize → Random Resized Crop (`scale_min=0.8`) | 97.73% | 93.37% | -1.50 |
| 12 | 07：Token Pool 16 → 8 | 97.74% | 93.22% | -1.65 |
| 13 | 07：Token Pool 16 → 24 | 97.74% | 93.33% | -1.54 |
| 14 | 07：layer3+layer4 → 仅 layer3 | 95.56% | 90.34% | -4.53 |
| 15 | 07：Dropout 0.1 → 0.2 | 97.82% | 93.81% | -1.06 |
| 16 | 07：前 2 epoch 冻结 backbone | 97.19% | 93.03% | -1.84 |
| 17 | 07：输入 512 → 384 | 97.73% | 93.56% | -1.31 |

08–17 中表现最好的是 15（验证 Accuracy 97.82%、Macro F1 93.81%），但仍低于 07。因此新增实验没有改变最佳单模型，最终单模型继续选择 07。

## 可以作出的受控结论

- `01 → 02`：Random Resized Crop 使 Macro F1 增加 0.67 个百分点；该结论适用于 ResNet50 + CE 基线。
- `03 → 04`：GeM 相对 GAP 增加 0.43 个百分点。
- `04 → 05`：Sub-center ArcFace 只增加 0.03 个百分点且 Accuracy 略降，对当前闭集物种分类的净收益有限。
- `02 → 06`：多尺度 Transformer 相对 ResNet50 基线增加 0.23 个百分点。
- `06 → 07`：完整训练配方增加 0.62 个百分点；由于同时改变多项设置，这一对比只能解释为组合收益。
- `07 ↔ 08`：在其余配置相同时，Focal 相对 CE 增加 2.05 个百分点。
- `07 ↔ 09`：启用 Mixup 相对关闭 Mixup 增加 1.56 个百分点。
- `07 ↔ 10`：启用 Cutout 相对关闭 Cutout 增加 1.21 个百分点。
- `07 ↔ 11`：当前 Transformer 配方中，直接 Resize 相对 `scale_min=0.8` 的 Random Resized Crop 增加 1.50 个百分点。这不与 `01 → 02` 矛盾，说明增强效果依赖模型和训练配方。
- `07 ↔ 12/13`：Token Pool 16 优于 8 和 24，分别高 1.65 和 1.54 个百分点；当前结果支持中等 token 网格。
- `07 ↔ 14`：layer3+layer4 多尺度融合相对仅 layer3 增加 4.53 个百分点，是新增消融中影响最大的结构因素。
- `07 ↔ 15`：Dropout 0.1 相对 0.2 增加 1.06 个百分点。
- `07 ↔ 16`：从第 1 个 epoch 开始微调 backbone，相对先冻结 2 个 epoch 增加 1.84 个百分点。
- `07 ↔ 17`：512 输入相对 384 增加 1.31 个百分点。

## 十个新增模型对四模型集成的复核

先在固定验证集上缓存旧 02/04/06/07 与新增 08–17 的逐样本概率，再以 0.1 为步长穷举最多四个非零权重、按验证 Macro F1 选择。所有可部署候选使用相同的 batch size 4、AMP 和无 TTA 推理条件。

验证集锁定的新候选是 `02/04/07/14 = 0.1/0.1/0.6/0.2`。14 单模型虽然较弱，但与 07 的预测分歧率为 4.09%，在验证集上提供了一定互补性。

| 方案 | Val Accuracy | Val Macro F1 | Test Accuracy | Test Macro F1 |
|---|---:|---:|---:|---:|
| 当前 02/04/06/07，`0.1/0.1/0.1/0.7` | **98.63%** | 96.36% | **98.43%** | **92.60%** |
| 新候选 02/04/07/14，`0.1/0.1/0.6/0.2` | 98.56% | **96.61%** | 98.20% | 92.26% |

同一 batch size 4 条件下复核测试集时，当前组合为 98.41% / 92.59%，新候选为 98.20% / 92.26%，新候选多错 11 张。因此验证 Macro F1 的 0.25 个百分点增益没有泛化到独立测试，不能据此替换当前部署集成。看到该测试结果后不再调整权重。

17 使用 384 输入，而当前 Flask 集成要求所有 ONNX 组件输入尺寸一致；离线候选搜索包含 17 后，最优组合仍未选择它，因此没有必要为它增加多尺寸预处理开销。

## 最终结论

1. 预先设计的 01–17 已全部完成，07 仍是当前最佳单模型。
2. 当前数据支持 Focal、Mixup、Cutout、多尺度 layer3+layer4、Token Pool 16、Dropout 0.1、直接微调和 512 输入这一组局部最优配置。
3. 现有 02/04/06/07 四模型概率集成仍是独立测试上的最佳研究和部署方案，不使用 TTA。
4. “完整”指预设的 17 组主效应实验已经闭环，不代表穷尽所有超参数、交互作用或证明全局最优。

## 实验边界

1. 每个配置只有随机种子 42；单次运行不能估计训练方差，也不能把 `std=0` 当作稳定性证据。
2. 验证集参与了 17 个配置与两轮集成候选选择，存在选择乐观；若继续研究，应重新留出未查看的最终测试集或使用嵌套交叉验证。
3. 本任务是 28 类 `species` 闭集分类，不是 Happywhale 原竞赛的 `individual_id` 开集检索，不能直接比较 MAP@5。
4. 独立测试来自同一 Kaggle 数据源的 group holdout，不等同于跨组织、跨地点、跨年份的外部验证。
5. 极少数类别样本很少，Macro F1 会被少量临界预测明显影响；结论应与逐类支持度和 Bootstrap 区间一起解释。
