# 最终完整消融实验报告

本报告对应 AutoDL 运行 `autodl_research_20260909-023128` 的 7 组完整消融结果。所有实验使用同一份按 `individual_id` 分组的 train/validation/test 划分、训练种子 42、划分种子 42、20 个 epoch 和确定性训练设置。独立测试集没有参与模型选择。

## 结果摘要

- 实验配置数：7
- 总训练次数：7（每个配置 1 个随机种子）
- 训练/验证/独立测试：40,277 / 5,409 / 5,347 张
- 类别数：28
- 最佳实验：`07_previous_best_transformer_recipe`
- 最佳验证 Accuracy：98.23%
- 最佳验证 Macro F1：94.87%

| 实验 | 模型与主要改动 | Val Accuracy | Val Macro F1 |
|---|---|---:|---:|
| 07_previous_best_transformer_recipe | Transformer + 多尺度 + Focal/Mixup/Cutout | **98.23%** | **94.87%** |
| 06_transformer_mean_ce_crop | 多尺度 Transformer + CE + Crop | 98.06% | 94.25% |
| 02_resnet50_ce_crop | ResNet50 + CE + Crop | 97.93% | 94.02% |
| 05_metric_arcface_gem_crop | GeM + Sub-center ArcFace | 98.17% | 93.78% |
| 04_metric_linear_gem_crop | GeM + Linear head | 98.24% | 93.75% |
| 01_resnet50_ce_resize | ResNet50 + CE + Resize | 97.69% | 93.35% |
| 03_metric_linear_gap_crop | GAP + Linear head | 98.00% | 93.32% |

## 受控比较

- `01 → 02`：只加入 Random Resized Crop，Macro F1 增加约 0.67 个百分点，说明减少背景/填充依赖有帮助。
- `03 → 04`：只把 GAP 改为 GeM，Macro F1 增加约 0.43 个百分点，GeM 在该数据上优于普通平均池化。
- `04 → 05`：只把 Linear head 改为 Sub-center ArcFace，Macro F1 仅增加约 0.03 个百分点且 Accuracy 略降，说明度量分类头对当前闭集物种分类收益有限。
- `02 → 06`：将 ResNet50 替换为多尺度 Transformer，Macro F1 增加约 0.23 个百分点，表明全局区域关系建模有一定帮助。
- `06 → 07`：加入历史最佳训练配方 Focal、Mixup、Cutout，Macro F1 增加约 0.62 个百分点；这是组合效果，不能归因到某一个组件。

## 实验边界

1. 只有一个训练随机种子，`std=0` 只表示当前每个配置运行一次，不能代表训练稳定性。
2. 验证集用于 checkpoint 和配置选择，独立测试集只用于锁定方案后的泛化评估。
3. 本报告评估的是 28 类物种闭集分类，不是 Happywhale 原竞赛的 `individual_id` 开集检索，也不能直接与 MAP@5 排名比较。
4. 本报告只包含完整消融；后续四模型集成属于单独的后处理研究，不改变本消融表的模型选择结论。

## 复现实验

```bash
bash scripts/autodl_run_research_pipeline.sh
```
